Mathematical Methodology

This system combines statistical time‑series forecasting with classic inventory optimization theory, matching the Python InventoryPredictionEngine implementation.

1. Simple Moving Average (SMA)

Average of the most recent window periods.

SMA = (Dₜ₋₁ + Dₜ₋₂ + … + Dₜ₋ₙ) / n
  • n: window size (e.g. 3 periods)

2. Weighted Mean (WMA)

Recent periods get higher weights: linear, exponential, or recent-heavy.

WMA = Σ(wᵢ·Dᵢ) / Σ(wᵢ)
  • wᵢ: linear (1,2,…,n) or exponential weights

3. Simple Exponential Smoothing (SES)

Level smoothing with alpha. Best for no trend or seasonality.

Sₜ = α·Yₜ + (1−α)·Sₜ₋₁
  • α: smoothing factor (0–1)

4. Holt's Double Exponential

Separates level (L) and trend (T).

Lₜ = α·Yₜ + (1−α)·(Lₜ₋₁ + Tₜ₋₁)
Tₜ = β·(Lₜ − Lₜ₋₁) + (1−β)·Tₜ₋₁
  • α: level smoothing, β: trend smoothing

5. Linear Regression

Fits demand = intercept + slope × time.

Demand = a + b·t
  • a: intercept, b: slope (trend)

6. Safety Stock & ROP

Buffer against demand variability during lead time.

SS = Z · √L · σ_daily
ROP = (d̄_daily · L) + SS
ROQ = max(0, ROP + D_monthly − Stock)
  • Z: 1.645 for 95% service level
